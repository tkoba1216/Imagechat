# Ocha.ru
> 毎日ひとつ、ほっとする瞬間を

その日の想い出を、そっと残せる写真投稿アプリ

## ✨ 特徴
- 📸 1日1投稿 - 大切な瞬間を記録
- 🎭 匿名投稿 - 気軽に共有できる
- ☕️ のんびり交流 - いいねだけのシンプルな機能
- 💭 ひとことメモ - 想いを添えられる（任意）

## 📱 アプリの使い方
1. 写真を選んで投稿
2. よかったら一言コメントを添える
3. みんなの投稿を見てリラックス
